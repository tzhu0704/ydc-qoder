# Project context

This repository develops a You.com-assisted Qoder plugin for public-web research. It is a development preview, not an approved marketplace listing. The current package bundles two Skills and a keyless You.com MCP connection. See [RESEARCH.md](RESEARCH.md) for sources, verified MCP behavior, and the TinyFish feature comparison; see [DEVELOPMENT.md](DEVELOPMENT.md) for release gates.

The public Qoder marketplace submission involves a plugin ZIP, listing information, self-test results, and review. Qoder's [Chinese extension guidelines](https://docs.qoder.com/zh/qoderwork/skill-marketplace-guidelines) require referenced Connector dependencies to be published, while its [plugin publishing instructions](https://docs.qoder.com/developers/publishing/plugins) describe reviewing bundled MCP services. Confirm how the target Qoder client and review team apply these requirements before submission.

No target client import, marketplace review, publisher authorization, or public listing is established by the files in this repository. Never commit personal credentials or test accounts. Repository visibility and GitHub destination are chosen by the publisher, not by this package.
